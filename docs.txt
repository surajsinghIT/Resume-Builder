Q?- How remember me works??
Ans- Firebase provides 3 way to remember user.
browserLocalPersistence:-	Keeps the user signed in even after browser restarts (“Remember me”).
browserSessionPersistence:-	Keeps user signed in only until the tab or window is closed.
inMemoryPersistence:-	Keeps user signed in only in memory, lost on page reload.
